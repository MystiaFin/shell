# Quickshell Configuration

My personal Quickshell desktop shell for Niri.

## Preview

[![Watch the demo](https://img.youtube.com/vi/G-VcE13d5as/maxresdefault.jpg)](https://youtu.be/G-VcE13d5as)

## Features

- Top status bar with workspaces, time, date, audio, microphone, media, battery, CPU, and memory information
- Application launcher with search and keyboard navigation
- Control center with volume, microphone, and media controls
- Utility center for brightness, notifications, Wi-Fi, and Bluetooth
- Wallpaper picker with image previews
- Dynamic colors based on the current wallpaper
- Notification popups
- Animated panel transitions and liquid-style visual effects

## Requirements

- Quickshell
- Niri
- `playerctl`
- Cava
- A Nerd Font

## Usage

```sh
quickshell -p ~/.config/quickshell
```
